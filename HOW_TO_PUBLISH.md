# Editing this site

The site is published with GitHub Pages from the repository `cambelh07-glitch.github.io` and is live at https://cambelh07-glitch.github.io.

## Editing

- Text lives in `index.html` (home page) and `projects/nova-transit-access.html` (project page). Comments marked with `=====` show where each section starts.
- Colors and fonts are set at the top of `assets/style.css`.
- To change the site, open a file on GitHub, click the pencil icon, edit, and commit. The live site updates within a few minutes.

## Updating the résumé

- The résumé section on the home page shows `assets/docs/Cambel_Hurst_Resume.pdf`. To update it, export the new résumé from Word as a PDF, name it `Cambel_Hurst_Resume.pdf`, and upload it to `assets/docs/` (Add file, then Upload files). The new file replaces the old one.
- Phones show an image instead of the PDF viewer. Replace `assets/img/resume-preview.jpg` with a screenshot or image export of the new résumé so the two match.
